# Supply Chain Control Tower Dashboard

##  Project Overview
This project is a comprehensive **Supply Chain Analytics Dashboard** built using **Power BI**. It is designed to help logistics managers and business analysts monitor key performance indicators (KPIs) related to sales, profit, and delivery performance.

The primary goal of this dashboard is to identify **Late Delivery Risks** and optimize **Shipping Modes** to improve customer satisfaction and profit margins.

##  Key Features
- **Real-time KPI Tracking:** Monitors Total Sales, Profit, Order Count, and Late Delivery Risk %.
- **Dark Mode UI:** Custom-designed "Glassmorphism" background for a premium, professional look.
- **AI Analytics:** Utilized the **Decomposition Tree** visual to drill down into profit drivers by Region and Category.
- **Geospatial Analysis:** Interactive map showing sales distribution across global markets.
- **Shipping Performance:** Comparative analysis of 'Standard' vs 'First Class' shipping modes to detect delays.

##  Tools & Technologies Used
- **Power BI Desktop:** For data visualization and reporting.
- **DAX (Data Analysis Expressions):** Used for calculating complex measures like `Avg Shipping Days`, `Late Delivery Rate`, and `Profit Margins`.
- **Power Query:** For data cleaning (handling date formats, null values, and type casting).
- **Excel/CSV:** Raw data source handling.

##  Key Insights from the Data
1.  **Late Delivery Risk:** Identified that specific regions have a >50% risk of late delivery, requiring immediate logistical intervention.
2.  **Customer Segmentation:** The 'Consumer' segment accounts for the majority of sales, but the 'Corporate' segment offers more stable shipping times.
3.  **Shipping Delay:** There is a significant variance between 'Scheduled' and 'Real' shipping days in the International Market.
